## 1. Overview
Программа реализует управление данными о студентах (фамилия, дата рождения, успеваемость). 
Основные функции:
- Ввод данных о 10 студентах.
- Сортировка по возрастанию среднего балла (SES).
- Поиск студентов младше 20 лет на дату 01.12.2010.

Программа разделена на модули:
- `interface.h`: Описание структур и прототипов.
- `server.c`: Логика обработки данных (сортировка, фильтрация).
- `client.c`: Ввод и вывод данных.
- `main.c`: Точка входа.
